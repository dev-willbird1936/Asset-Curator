# Security

Maintainer: dev-willbird1936. Report sensitive bugs using GitHub private vulnerability reporting when available. Do not post credentials or exploit details publicly.

This plugin reads public third-party data and writes local assets. It constrains network hosts, archives, resource sizes and output paths. Saved browser permission is separate from host approval. Safe licensing mode is conservative filtering, not legal clearance. See the plugin README for process, filesystem, network and credential disclosures.
