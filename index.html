How it was made

  • Every run got the identical brief and the same Three.js 0.184 runtime, in a clean Hermes profile, with Sonnet 5.5 requested at high effort.
  • The game code is exactly what the model returned. Only a small hosting header was added so the files load on a static site.
  • "Create only" is a second run. The test harness wrongly blocked three sprite calls in the first one, so it is not shown.
  • Each game was played once by a keyboard bot. Sound was not listened to, and taking damage and running out of time were not tested.
